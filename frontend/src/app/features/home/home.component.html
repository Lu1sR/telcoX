Bienvenido al Portal de Consumo TelcoX

📱 Portal de Autoservicio de Telecomunicaciones

Un sistema full-stack listo para producción que permite a los clientes ver sus datos de consumo, saldos de cuenta y métricas en tiempo real.

✅ Implementación Completa:

  • ✅ Backend: API REST Django con Django REST Framework
  • ✅ Frontend: Aplicación Angular 17 con arquitectura modular
  • ✅ Base de Datos: MySQL 8.0 con datos de prueba
  • ✅ Pruebas: 159/163 tests pasando (97.5% cobertura ~82%)
  • ✅ Contenedorización: Docker Compose para despliegue
  • ✅ Documentación: API docs completos (Swagger/OpenAPI)

🎯 Características Principales:

  • 📊 Seguimiento de consumo en tiempo real (Datos, Minutos, SMS)
  • 📈 Indicadores visuales de progreso codificados por colores
  • 💰 Resumen de cuenta con saldo y estado
  • 📱 Diseño responsivo para todos los dispositivos
  • ⚡ Manejo profesional de estados (carga, error, vacío)
